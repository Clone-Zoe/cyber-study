# TCP 三次握手与四次挥手

## 三次握手（建立连接）

客户端                              服务端
   │  ① SYN=1, Seq=x                  │
   │ ─────────────────────────────>   │
   │      "我想连你，我的序号是x"     │
   │                                  │
   │  ② SYN=1, ACK=1, Seq=y, Ack=x+1  │
   │ <───────────────────────────     │
   │      "收到，我也同意，序号是y"   │
   │                                  │
   │  ③ ACK=1, Seq=x+1, Ack=y+1       │
   │ ─────────────────────────────>   │
   │      "好的，连接建立！"          │
   ▼                                  ▼
              连接建立，开始传数据

## 四次挥手（断开连接）

客户端                              服务端
   │  ① FIN=1, Seq=u                  │
   │ ─────────────────────────────>   │
   │      "我要断开"                  │
   │                                  │
   │  ② ACK=1, Seq=v, Ack=u+1         │
   │ <─────────────────────────────   │
   │      "收到你的断开请求"          │
   │                                  │
   │  （服务端可能还有数据要发）      │
   │                                  │
   │  ③ FIN=1, ACK=1, Seq=w, Ack=u+1  │
   │ <─────────────────────────────   │
   │      "我也发完了，可以断开"      │
   │                                  │
   │  ④ ACK=1, Seq=u+1, Ack=w+1     │
   │ ─────────────────────────────&gt; │
   │      "收到，彻底断开"            │
   ▼                                  ▼
                连接关闭

## 为什么是三次握手？
- 两次不够：服务端不知道客户端是否收到了自己的 SYN
- 三次刚好：双方都确认了自己能发、对方能收

## 为什么是四次挥手？
- TCP 是全双工的（双方同时能发能收）
- 断开需要双方分别确认："我不再发数据了"
- 所以比握手多一次
